گلزار — نسخه وب قابل نصب (PWA)
================================
این نسخه را می‌توانی با گوشی اندرویدی و اینترنت راه‌اندازی کنی؛ برای نصب مثل یک اپ، باید فایل‌ها روی یک نشانی HTTPS میزبانی شوند. باز کردن index.html از داخل ZIP به‌تنهایی نصب PWA را فعال نمی‌کند.

روش پیشنهادی با گوشی:
1) فایل ZIP را استخراج کن (از برنامه Files / مدیریت فایل گوشی).
2) در سرویس میزبانی استاتیک مثل GitHub Pages یک مخزن بساز و فایل‌های index.html، manifest.webmanifest، sw.js و پوشه icons را بارگذاری کن.
3) میزبانی را فعال کن و نشانی HTTPS صفحه را با Chrome باز کن.
4) از منوی سه‌نقطه Chrome گزینه «Add to Home screen» یا «Install app» را انتخاب کن.
5) آیکون گلزار روی صفحه اصلی ظاهر می‌شود. پس از بارگذاری اولیه، پوستهٔ برنامه می‌تواند آفلاین هم باز شود.

نکته‌های مهم:
- نام گزینه‌ها بسته به نسخه اندروید/Chrome ممکن است کمی فرق کند.
- این پروژه به اینترنت برای میزبانی و اولین بارگذاری نیاز دارد.
- این نسخه تقویم نمونه دارد؛ همهٔ مناسبت‌ها، تاریخ قمری رسمی، اوقات شرعی، اذان و اعلان‌ها هنوز کامل نیستند.
- برای استفاده از GitHub Pages ممکن است لازم باشد حساب رایگان بسازی.
